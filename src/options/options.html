判定阈值

人类置信度 0–100（100 = 几乎确定人工）。分数越低越可疑。

云端二审

规则初审分数落在模糊带内时，将回答正文发送至你配置的 LLM 服务（默认 DeepSeek）复核。 未配置 API Key 时仅使用本地规则。

Key 仅保存在本机浏览器（chrome.storage.local），不会随账号同步。

保存时该提示词将整体覆盖默认提示词（正文作为单独的 user 消息发送）。支持保留字 {{ai_slot_ctx}}：调用时替换为一审（规则引擎）的规则分与命中痕迹；模板不含保留字时自动追加到末尾。改回默认内容即等同使用内置。

按所用服务商兼容性填写，保存前校验 JSON 语法。默认（DeepSeek）为关闭思考模式 + temperature 0—— 思考模式下 temperature 等参数不生效，关闭可降延迟/成本并让 temperature 生效。 留空则不发送任何额外参数，兼容性最好（纯 OpenAI / 严格校验的服务商）。

输入窗口与界面行为

文章设置

文章详情页（/p/xxx）的判定参数，与回答判定独立；判定阈值与二审权重与回答共享（全站尺度一致）。 默认「头尾各半」：上限 4000 字、头尾各取 2000——万字长文也能覆盖结尾套话。

自定义 AI 痕迹规则

新增/编辑/删除自己的判定正则，与内置规则共同参与扣分（每次命中扣 weight 分，最多计入 cap 次）。 正则需为 JavaScript 语法，保存前会校验。
