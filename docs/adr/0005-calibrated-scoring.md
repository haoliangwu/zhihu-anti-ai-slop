# 校准打分：从加性扣分制到逻辑回归权重（方案 A）

Status: accepted

一审评分从「命中固定句式即扣固定分」（`score = 100 − Σ min(count,cap)×weight`，权重为手拍整数）改为「逻辑回归校准」（`score = round(σ(Σ w_i·x_i + b) × 100)`）。权重由 C-ReD 知乎问答语料（人类 2,956 + 9 个 LLM 26,115 条）离线拟合产出，运行时仍是纯 JS（sigmoid + 点积），零依赖零网络。

**Considered Options**:

- **保持手拍扣分制**：权重无概率语义、分数不是置信度，且固定句式可被改写绕过；对知乎域内人类常用模式（冒号、句号当顿号等）存在系统性惩罚。排除。
- **困惑度/概率曲率类（GPTZero/DetectGPT/Binoculars）**：需中文 LM 逐 token 前向，客户端不可行（ADR-0002 已排除 82–409MB 本地模型）；Binoculars 多语含中文 F1 回落至 0.54–0.88。排除。
- **纯 JS 统计特征 + 分类器（方案 B）**：句长波动/字符熵/TTR 等正交信号可补强「句式未命中但节奏机械」的文本，但短文本不稳、正式文体误报多，且数据与工作量更大。暂缓，待方案 A 稳定后另立票。
- **规则命中数 → 逻辑回归校准（选定）**：现扣分制本质就是未校准的线性模型，A 是其校准化推广；先例 HC3 已在中文问答上用「特征 + 逻辑回归」验证；运行时仅 sigmoid+点积。

**Consequences**:

- **评估（C-ReD 留出集，n=5,814）**：AUROC 0.676 → **0.816**；Brier 0.687 → **0.192**；平衡评估子集（部署语义）AUROC 0.824 / Brier 0.166。门槛（AUROC 或 Brier 至少一项优于旧制）通过。
- **权重方向由数据决定**：冒号滥用、句号当顿号、伪口语、伪亲密称呼、破折号反复、编号式、强化词在知乎问答域拟合为**人类信号**（人类 KOL 比提示词约束的 LLM 更常用）——旧扣分制对这些的惩罚是域偏差，校准权重按数据方向自动调整；面板改显示「±贡献」（正 = 偏向人类）。4 个基率≈0 的噪声特征（元评论/励志结尾/成语堆砌/死隐喻）置零。
- **分数分布整体下移**（人类中位 67 分），旧阈值 40/70/[20,80] 会误标 66% 人类 → 阈值随模型数据落地：**确定 ≤30（人类误报 3.7%）、疑似 ≤50（Youden J）、模糊带 [30,50]**（云端只处理疑似区，控制成本）；选项页仍可编辑。票 07 修订：模糊带下界下探至 **15**（确定区左段 15–29 分可能含校准误报，实测 26 分手写回答，入带即送二审挽救；低于 15 证据充分不再外发）。
- **设置迁移**：settingsVersion 版本化迁移——仅当存储值仍是旧默认（用户未自定义）时自动升级阈值与文章跳过字数（300→800），尊重显式配置。
- **回退开关**：`USE_CALIBRATED` 代码级常量，切回后与旧行为完全一致。
- **已知误报类**：学术/公文式行文（首先/其次/综上所述 枚举 + 总结收尾）在权重下得分偏低（实测 5 分确定 AI）；文学/古风文本已正确放行（《滕王阁序》54 正常）。学术误报可调阈值/二审/手动覆盖，后续方案 B 的统计特征可能缓解。
- 保留：自定义正则的扣分语义（sigmoid 结果上按原 deduct 叠加）、二审加权融合（0.6·cloud + 0.4·rule）、缓存键（含一审摘要，自动失效重判）。
