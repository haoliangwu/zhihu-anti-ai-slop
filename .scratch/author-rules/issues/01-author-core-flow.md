# 01 — 作者识别与屏蔽/信任核心流程

Type: task
Status: ready-for-agent
Priority: P0

**Blocked by:** 无（可立即开工）

从回答卡片提取作者，建立作者规则数据层，并把规则检查插到判定流程最前端：已屏蔽 → 整卡占位；已信任 → 一轮不跑。用户端到端行为：在问题页点开任意角标面板，即可屏蔽/信任该作者，全页该作者卡片即时生效。

**验收：**

- [ ] 回答卡片可提取作者（`zhihu.com/people/<token>` 为主键，昵称用于显示）；匿名回答识别为"不可操作"
- [ ] 角标面板出现「屏蔽该作者」「信任该作者」按钮（匿名卡不显示）
- [ ] 屏蔽后：卡片立即替换为占位条「已屏蔽作者 X」+ [查看][取消屏蔽]，不产生任何提取与判定调用
- [ ] [查看] 临时展开正文；页面重分析后仍保持屏蔽
- [ ] 信任后：该作者卡片一轮不跑、零角标，仅低调灰色小签「已信任」，点击可取消信任 / 改为屏蔽
- [ ] 屏蔽/信任后，本页该作者全部卡片（含已分析的）即时应用规则
- [ ] 作者级规则优先于卡片覆盖与引擎判定
- [ ] 规则跨页面持久化（刷新、重开浏览器保留）
