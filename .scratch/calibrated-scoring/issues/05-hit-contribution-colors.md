# 05 — 校准命中贡献颜色语义适配（正=偏人类绿、负=偏 AI 红）

Type: bug
Status: done
Priority: P2

**发现途径：** 校准打分引擎上线（票 02）后，用户在误报诊断交流中指出：理由面板命中清单全部显示红色，但校准制贡献有正负语义（正 = 偏向人类），"人类信号"条目也显示红色，语义矛盾。

## 根因

1. 票 02 校准制上线后，命中项从「固定扣分」变为「带符号 logit 贡献」（`contribution = count × weight`，正 = 偏人类、负 = 偏 AI）；
2. 但命中清单样式 `.zys-hits li` 仍是旧扣分制时代遗留：硬编码红色（`content.css:197-206`，当时"命中 = 负面 = 红色"语义成立）；
3. `content.js` 渲染命中项时未按 `contribution` 符号加区分 class → 实测页面里「冒号滥用 ×4：+1.03」（正贡献、人类信号）与「句长齐整 -0.56」（负贡献）同为红色 `rgb(230, 67, 64)`。

**本质：** 校准制给特征引入了方向语义（数据拟合方向，见 ADR-0005：冒号/句号当顿号/伪口语在知乎域为人类信号），UI 未同步升级——样式停留在"命中即负面"的旧心智。

## 修复

- `src/content/content.css`：`.zys-hits li` 去掉硬编码红底/红边/红字，拆为两套样式：
  - `.zys-contrib-neg`（红，偏 AI）× `.zys-contrib-pos`（绿，偏人类）；
  - 无 `contribution` 字段的条目（回退扣分制、用户自定义正则扣分）统一按负面红色显示，扣分语义不变。
- `src/content/content.js`：渲染命中项时按 `contribution` 符号加 `zys-contrib-pos` / `zys-contrib-neg` class；无字段时默认 `zys-contrib-neg`。
