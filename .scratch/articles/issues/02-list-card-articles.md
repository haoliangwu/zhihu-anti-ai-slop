# 02 — 列表卡片文章判定

Type: task
Status: ready-for-agent
Priority: P1

**Blocked by:** 01

首页/问题页的文章卡片纳入判定范围，与回答卡片同语义：折叠摘要不足 300 字走「跳过」，展开全文自动重分析，作者规则一致应用。用户滚动时间线即可看到文章卡片的判定角标。

**验收：**

- [ ] 首页/问题页文章卡片出现判定角标（需探测卡片 class 并纳入选择器）
- [ ] 折叠摘要 <300 字 → 显示「跳过」角标（与回答卡片语义一致）
- [ ] 展开全文（正文变化）后自动按全文重分析
- [ ] 已屏蔽/信任作者的文章卡片行为与回答卡片一致（占位 / 零标记+小签）
- [ ] 文章卡片与回答卡片判定互不干扰（各自的标识维度、缓存与预算隔离）
